# Text Patch 性能基准可视化方案

状态：讨论中。

## 已确认

- 性能测试可视化工具单独作为一个包，不放入 `text-patch` 包内。
- 性能测试可在浏览器和 Node.js 环境运行。
- 工具绘制性能随输入规模增长的曲线。
- 最终数据通过本地启动的 server，在浏览器中查看。
- 现有项目引用这个独立包。

## 待确认

- 独立包的名称和目录。
- “现有项目”具体指哪个项目，以及引用新包的用途和依赖方向。
- 测量哪些公开 API，以及单行、多行、修改密度等测试场景。
- 输入规模、重复次数、统计量和曲线坐标口径。
- 浏览器端如何加载现有 TypeScript 实现，以及两种环境如何保存和展示测试结果。
