# text-patch 独立仓库

## 已确定

- 本包名称改为 `text-patch`，目录、npm 包名和 GitHub 仓库名保持一致。
- 在包目录内建立独立的 Git 仓库，不修改外层主仓库。
- 将本包发布为公开的 `wintercn/text-patch` GitHub 仓库。
- 本包自有代码采用 MIT 协议；`tests/google/` 的迁入材料保留 Apache-2.0 声明，`tests/vscode/` 的迁入材料保留 MIT 声明。

2026-09-23 查询 npm 官方 registry，`text-patch` 尚无已发布包；这不保证后续发布时名称仍可用。

## npm 包构建与文档

- 公开入口保留现有 `createPatch`、`createCharacterPatch`、`createLinePatch`、`applyPatch`、`PatchOpcode` 和类型定义，不改变 API。
- 使用 TypeScript 编译 `src/`，生成可直接导入的 ESM JavaScript 和类型声明。包入口指向 `dist/`，npm 打包前自动构建。
- npm 包包含 `dist/`、`src/`、`docs/`、根目录 README、许可证和包元数据；不包含测试材料。源码继续公开在 GitHub 仓库，也随 npm 包分发。
- README 说明安装、最小用法、公开 API、Patch 数据格式、容量参数、UTF-16 行为、测试和许可证；算法细节仍由 `42-Markdown Patch算法.md` 说明。
- 发布前验证完整测试、构建产物、打包文件清单，以及从打包结果安装后的实际导入。首次发布版本在发布前确认。

## 本地验证

在仓库根目录执行 `npm install`、`npm run build` 和 `npm test`。`npm run build` 从 `src/` 生成 `dist/` 下的 ESM JavaScript 与 `.d.ts` 声明，`dist/` 是生成文件，不提交到 Git。`npm pack --dry-run` 会执行打包前构建，并列出实际要发布的文件；实际打包安装后，还需从已安装的 `text-patch` 入口执行一次生成、应用往返测试。README 中的文档链接指向公开仓库，使 npm 页面也能访问完整说明。
